# Interester Agent Instructions

A personalized content monitoring system that allows users to register interests and receive AI-curated summaries from across the web.

## Essentials
- **Package Manager**: Use `npm`.
- **Environment**: Tauri v2 + SvelteKit.
- **Development**: `npm run tauri dev`
- **Build/Check**: `npm run check` (Svelte/TypeScript check).
- **Communication**: I value constructive criticism and discussion. Feel free to point out mistakes or suggest improvements without being solicitous.
